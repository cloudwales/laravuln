# laravuln

This is my first public Go project that I hope someone will find usefull. I've used this myself for a little while, but thought it may be a good idea to release it after more vulnerabilities were found in the wild. The docs are generated by Ai because I'm rubbish at this part, but have updated a lot of it.

**Terminal scanner for Laravel/Composer dependencies.**  
Finds vulnerable packages (including RCEs, auth bypasses, and other nasty stuff) by parsing `composer.lock` and checking the packages against OSV.dev.

Built for any security-conscious Laravel devs who want to catch critical vulns that have been published **before** they hit production.

## Features

- Parses `composer.lock` (including dev dependencies)
- Batch queries **OSV.dev** (Packagist ecosystem) — best source for Composer vulns + public exploits
- Pretty colored table output with severity highlighting (CRITICAL in red, etc.)
- PoC hunting (`--pocs` flag) — highlights references that look like exploits/PoCs
- JSON output mode for CI/CD
- Exit code 1 when vulnerabilities are found (perfect for pipelines)
- Lightweight — only standard library + Cobra + tablewriter + fatih/color

## How to use 
Make sure you have Golang installed and then in the laravuln directory run the below commands.

```bash
# Build from source
go build -o laravuln .

# Optional: Add systemwide
sudo mv laravuln /usr/local/bin/

# Then from any Laravel project run
./laravuln 
```
